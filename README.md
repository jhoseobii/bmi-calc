# BMI Calc

A simple Body Mass Index (BMI) Calculator built with HTML, CSS, and JavaScript.  
This web app allows users to quickly calculate their BMI based on height and weight and see the corresponding BMI category.

About

This project implements a lightweight, responsive BMI calculator that takes user input for height and weight to compute the BMI using the standard formula:
BMI = weight (kg) / (height (m) × height (m))


Users are then shown their BMI value and the associated health classification.

---

Features

- Input fields for **height** and **weight**
- BMI calculation using the standard formula
- Displays BMI value and category
- Simple and clean user interface
- Works on desktop and mobile browsers

Installation

1. Clone the repository
   git clone https://github.com/jhoseobii/bmi-calc.git
2. Go into the project directory
3. Open the app
Open index.html in your web browser.

Usage

Enter your height (in meters or centimeters depending on UI).

Enter your weight in kilograms.

Click the Calculate button.

View your BMI result and category.
